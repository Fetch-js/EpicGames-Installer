# Epic Games Launcher Инсталлер от @MonoMaxiz
### <center>[English](README_EN.MD)</center>

Пользовательский интерфейс установщика для настольных компьютеров, созданный с использованием Tauri 2, «чистого» JavaScript и нативного механизма копирования на C++20.

## Разработка

Требования: Node.js, Rust, Visual Studio Build Tools с набором инструментов для разработки настольных приложений на C++ и WebView2.

```powershell
npm install
npm run tauri dev
```

## Загруженный пакет

Укажите в файле `src-tauri/src/lib.rs` в начале кода значение `PAYLOAD_URL` в виде прямого HTTPS-URL-адреса ZIP-архива. Установщик загрузит архив, безопасно распакует его во временный каталог и передаст извлеченные файлы в нативный механизм копирования на C++. Временные файлы удаляются автоматически.

Ожидаемое имя главного исполняемого файла для ярлыка на рабочем столе — `EpicGamesLauncher.exe`.

Переведено с помощью DeepL.com (бесплатная версия)

## Релизная сборка

```powershell
npm run tauri build
```
